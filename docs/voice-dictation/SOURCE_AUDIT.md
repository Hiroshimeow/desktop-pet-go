## Handy: verified capabilities and limitations so far

Pinned-source files read: `src-tauri/src/cli.rs`, `main.rs`, `actions.rs`, `shortcut/handler.rs`, `transcription_coordinator.rs` (including all tests), `paste_tx/windows.rs`, `engine_supervisor/{protocol,worker}.rs`, `portable.rs`; targeted portions of `managers/transcription.rs` and `lib.rs`. Full capture, supervisor, clipboard and history review still pending.

- Coordinator is a serial effect executor with pure tested state machine: toggle, push-to-talk and hold-or-toggle, 300ms configurable hold, 30ms keyboard debounce, 50ms release grace for X11 repeat. Busy presses remembered/forgotten to preserve toggle parity; cancel abandons pending start. Desktop Pet needs an explicit visible busy/queued policy, never stale target reuse.
- `actions.rs` start loads ASR/VAD off-thread and checks model availability before opening mic; readiness cue follows actual samples, generation invalidated on stop. Stop saves WAV concurrently, finalizes stream (batch fallback only if no usable stream result, not if cancelled), checks cancel generation before history/paste. Postprocess can call remote LLM but only separate configured action; must not reuse cloud behavior implicitly.
- `managers/transcription.rs::start_stream/run_stream_worker/finalize_stream` provides committed/tentative overlay updates for capabilities-advertised streaming models. Whisper Medium advertises **no streaming**. Nemotron 3.5 advertises VI and streaming. Frontend events are not yet shown to be an external supported API.
- CLI controls: `--toggle-transcription`, `--cancel`; headless `--transcribe-file`, `--repeat`, `--json`, `--model`, `--device-index`, lists. No public CLI session-scoped live event subscription or output-ownership/paste suppression option observed. Headless is batch and separate instance, not resident hotkey architecture.
- Important new integration candidate: `main.rs` recognizes internal `--transcribe-worker` before Tauri/CLI/single-instance. `engine_supervisor/protocol.rs` exposes framed JSON + float32 PCM request/response (`Hello`, `Load`, `Run`, `StreamBegin`, `Feed`, `Finalize`, `StreamReset`). `worker.rs` isolates native engine, exits immediately on stdin EOF, keeps model/session resident, returns committed/tentative/full. This is **internal unversioned IPC, not a supported external embedding contract**. Actual installed v0.9.8 probe rejected `--transcribe-worker` with exit 2 (`unexpected argument`); framed reader then raised `EOFError: worker EOF`, child cleaned up. Default-branch capability is unavailable in installed release. Exact release source was fetched separately at `14f6f0d31cb22a4268acfbddba3052820fd0a06e`; compatibility/distribution/license work remains G04. Do not claim working resident integration or silently ship this as stable API.
- `paste_tx/windows.rs` uses dedicated message-only worker, delayed CF_UNICODETEXT, WM_RENDERFORMAT reads, clipboard sequence guard, privacy markers excluding history/cloud monitoring, native bitmap copying + memory-format snapshot, bounded timer evaluation in `paste_tx/mod.rs` (200ms quiet interval, 8s timeout). **This transaction path is debug/settings-gated**; do not equate current source with enabled production behavior in the installed release. Limitations: unsupported native formats skipped; restore sequence check outside clipboard-open critical section appears vulnerable to TOCTOU; a clipboard read is not proof intended target pasted. ## local-live-caption-engine donor assessment

Read `segmenter.py`, `stabilizer.py`, `stitcher.py`, `scheduler.py` fully at existing revision.

- Good technique: pre-roll excludes current speech frame before adding it once; explicit speech/endpoint/min-speech, hard-cut audio overlap, latest pending partial replacement.
- **Not safe to copy wholesale:** stabilizer can shrink/change an already stable prefix, character-level agreement can stabilize half a word, old agreement can be returned with an unrelated new hypothesis. Stitcher deduplicates arbitrary single-character suffix/prefix even without audio overlap evidence and truncates deliberate repeated two-word phrases. Scheduler mandatory final FIFO/results are unbounded and executes partial/final concurrently on the same backend; conflicts with bounded resident-model ownership unless backend explicitly supports it.
- Existing tests are useful fixtures, not proof of human VI/EN accuracy or all invariants. Reuse only proven parts after adversarial deterministic tests; avoid treating marketing/README as correctness.
