## Public engine reuse versus unavailable hidden IPC

Exact released public API: `transcribe-cpp-sys0.2.4/include/transcribe.h`. Actual implementation portions inspected: `src/transcribe.cpp:1100–1280` stable-prefix dispatch, UTF-8 boundary, agreement/history and finalize; not whole native implementation.

- C lifecycle `transcribe_open/session_free`, explicit strict CPU load params, `stream_begin/feed/get_text/finalize/reset`, installed abort callback and `was_aborted` are real exported APIs; **native smoke exit0** in BENCHMARK.md.
- 0.x ABI can break; verify exact version/size/alignment and package matching headers/provider, never use0.3.1 declarations with0.2.4 DLL. Runtime commit unknown prevents binary/source equivalence claim beyond tested API/version.
- One compute operation across all sessions on each model at a time; model outlives sessions, sessions single-thread owner. Copy borrowed UTF-8 strings before next mutation. Abort callback installed before compute and kept alive; only flag changed concurrently. Header explicitly says **no mid-encoder abort**; already-set abort probe is not measured in-flight cancellation latency.
- Stream UI API distinguishes raw full, append-only committed, volatile tentative. Header `stream_text` warns committed+tentative may diverge from raw full after wrong commitment; finalize never rewrites committed bytes. **Raw full is authoritative final**, not permanently committed preview. G07 must test divergence, UTF-8/token boundaries and model family semantics.
- Source maps Parakeet architecture to native irreversible commit, Moonshine to token agreement, others to generic repeated-text agreement (default3), not one universal stability algorithm. This Nemotron sample emitted only committed updates; no nonempty tentative behavior proven.
- Nemotron native stream is a **concrete lawful-engine reuse candidate**, not chosen/default quality solution. Incorrect synthetic VI transcript, full model license, human VI/EN accuracy, performance/idle/resource and distribution tests still block adopting it as an accepted backend.
- Reproducible research probe `probes/transcribe_release_probe.py` exercises only existing DLL/local synthetic WAV; struct-derived notice retained. It is not loaded by product, does not create a second speech system, and does not ship any DLL/model/audio/secret.
