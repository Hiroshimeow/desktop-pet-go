## Windows adaptation and scope conclusions (G03 only)

1. OSW validates the **stop → local final → intentional paste** workflow and mature ownership/latency techniques. It does not satisfy genuine live text, intended-target/caret verification, Windows integrity/secure-field safety or measured VI accuracy. Those remain mandatory Desktop Pet gates; no acceptance reduction.
2. Exact OSW short-tap toggle and double-Esc defaults differ from SPEC's separate hold short-press discard/immediate Esc. Preserve the explicit approved Windows contract; do not silently advertise identical trigger semantics.
3. Borrow resident model/fresh per-record decode, serial capture, tail/resampler preservation, cancellation identity fences, nonactivation/bounded geometry and clipboard ownership guard. Concrete owners remain existing Go UI/controller and Python audio/inference; **G05** determines narrow implementation files after G04 evidence.
4. Full media-import library, Hebrew model catalog, macOS modifier/mouse onboarding keyboard illustration, alternative platform engines, cloud providers, agent framework and GPU orchestration are **OUT_OF_SCOPE** for this goal unless a failing locked gate justifies them.
5. Stronger target/clipboard/lifetime safety must be Windows tested, not copied as a claim from OSW. No source-parity row passes G06–G14.
